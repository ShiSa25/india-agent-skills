# Sources

Rules as of 2026-11-01. A bullet is either a page that was opened or an explicit UNVERIFIED tag.

- [Payment webhook signature verification](https://www.cashfree.com/docs/api-reference/payments/latest/webhooks/signature-verification) — opened 2026-11-01. `expectedSignature = Base64(HMAC-SHA256(x-webhook-timestamp + rawBody, client secret))`. The worked timestamp on the page is `1617695238078`. The body must be raw. Partner webhooks use the partner API key.
- [Payloads and signatures](https://www.cashfree.com/docs/api-reference/webhooks/payloads-and-signatures) — opened 2026-11-01. Payment Gateway, Payouts V2, Secure ID, and PPI share that header algorithm. Payouts V1 (Cashgram) is form-encoded and is out of scope.
- [Webhook version 2025-01-01](https://www.cashfree.com/docs/api-reference/payments/previous/v2025-01-01/payments/webhooks) — opened 2026-11-01. Sample headers include `x-webhook-version: 2025-01-01`, `x-webhook-signature`, `x-webhook-timestamp: 1746427759733`, and `x-idempotency-key`. Keep `payment_amount` text such as `170.00`. Do not let a JSON parser turn it into `170`.
- [Payment status webhooks](https://www.cashfree.com/docs/api-reference/payments/latest/payments/webhooks) — opened 2026-11-01. The current sample table also shows version `2026-01-01` with the same signature headers and `x-idempotency-key`. Version `2023-08-01` omits that key.
- [Webhook idempotency](https://www.cashfree.com/docs/api-reference/payments/latest/webhooks/idempotency) — opened 2026-11-01. Only `payment_status` `SUCCESS` is terminal. `FAILED`, `NOT_ATTEMPTED`, and `PENDING` are not. A later `SUCCESS` after `FAILED` still fulfils.
- [Webhooks overview](https://www.cashfree.com/docs/api-reference/payments/latest/webhooks/overview) — opened 2026-11-01. At-least-once delivery. The overview text says `x-idempotency-header`. The 2025-01-01 header table says `x-idempotency-key`. This skill follows the header table.
- [Subscriptions signature verification](https://www.cashfree.com/docs/api-reference/payments/latest/subscription/webhook-signature) — opened 2026-11-01. Same `timestamp + rawBody` Base64 HMAC. Recommends a 5 minute replay window. The Payment Gateway signature page does not publish a number. This skill uses 300 seconds for PG webhooks as that recommendation.
- Millisecond-versus-seconds detection (a numeric timestamp greater than 1e12 is milliseconds) — UNVERIFIED. Cashfree samples are milliseconds. Cashfree does not publish the threshold. `verified` is false and a result that applies the detector sets `confirm` true.
- [Cashfree MCP server](https://www.cashfree.com/docs/tools-ai/mcp-server) — opened 2026-11-01. Orders, refunds, settlements, and payment links go through this server at `https://mcp.cashfree.com/mcp`. This skill does not call the Cashfree API.
